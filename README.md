## Featured Projects

### 1. AEGIS — Explainable Spacecraft-Health Monitoring & Decision Support *(Winning Project, Hackathon 2026)*

A spacecraft-health monitoring prototype turning multi-channel telemetry (`battery voltage`, `temperature`, `wheel speed`, `power`) into explainable fault alerts and safety-checked recovery recommendations through a **detect → explain → recommend → safety-check** workflow.

**Highlights**
- Added telemetry-quality checks (`missing`, `stale`, `noisy` data) so sensor/data issues are not mistaken for hardware faults.
- Combined statistical and ML detection over multi-channel patterns and ranked likely root causes with matched and contradicting evidence.
- Separated detection from action approval using a rule-based guard over a predefined action library; built a simulated spacecraft with fault injection.
- Detected **29 of 40 injected fault episodes (72.5%)** in saved simulation benchmarks, including **5 of 5 reaction-wheel friction episodes**.

**Tech:** Python · Machine Learning · Anomaly Detection · Fault Simulation · Explainable AI
