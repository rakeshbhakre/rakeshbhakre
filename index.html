PROJECT_02

Intelligent Traffic Surveillance System

Computer Vision · 2025 · Published Research
📄 Published paper Real-time
  • I built a system that detects 5 distinct traffic violations from live CCTV / RTSP streams, using YOLOv8 for detection and DeepSORT to track each vehicle across frames.
  • I applied homography to map the image plane onto the road plane, so I could estimate speed with only ~3.2 km/h of error.
  • I wrote an HSV-based traffic-signal state detector and a rule engine that holds 18–22 FPS on CPU alone — no GPU needed to deploy it.
  • I added a number-plate OCR pipeline with EasyOCR, served through FastAPI with SQLite evidence storage.
  • I wrote the work up and it was published as a research paper.
